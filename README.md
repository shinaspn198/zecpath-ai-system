# Zecpath AI Recruitment System 🚀

## Overview

Zecpath AI Recruitment System is a modular AI-powered recruitment platform designed to analyze candidates, evaluate resumes, and generate intelligent hiring insights.

The project follows a scalable AI engineering architecture with separate modules for parsing, ATS evaluation, screening, interview analysis, and scoring.
